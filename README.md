# 컴퓨터 탐험대

초등학교 방과후 컴퓨터 수업의 마지막 5~15분을 위한 광고 없는 블록 탐험형 컴퓨터 연습 웹서비스다. 숲·광산·성·섬·마을의 5개 미션에서 클릭, 드래그, 한글·영문 타자와 컴퓨터 기초를 연습한다.

## 실행 방법

별도 설치 없이 `index.html`을 Chrome에서 열면 된다. 로컬 웹서버를 사용할 경우 프로젝트 루트를 정적 파일로 제공한다.

## 개발 명령어

이 프로젝트는 빌드 과정이 없다. HTML·CSS·JavaScript를 수정한 뒤 브라우저를 새로고침한다.

## 폴더 구조

```text
/
├─ index.html                 # 화면, 스타일, 게임 로직
├─ PROJECT_CONTEXT.md         # 다음 개발자가 가장 먼저 읽을 문서
├─ prd.md                     # 제품 요구사항
├─ ROADMAP.md / TASKS.md      # 개발 계획과 작업 상태
├─ SAFETY_REQUIREMENTS.md     # 아동 안전 기준
├─ DESIGN_SYSTEM.md           # UI 기준
├─ USER_FLOW.md / TEST_PLAN.md
└─ docs/                      # 아키텍처, 게임 규칙, 콘텐츠 지침
```

## 현재 주요 기능

- 블록 세계 시작 화면과 5개 지역 탐험 지도
- 3단계 빛 블록 숲과 황금 큐브 보너스
- 정리 광산, 한글 건축 성, 영문 항해 섬, 컴퓨터 수리 마을
- 점수, 진행률, 정확도, 반응속도·완료 시간
- 일시정지, 다시 하기, 탐험 지도 이동
- 소리 기본 끄기와 애니메이션 감소 지원
- 최근 결과와 소리 설정의 로컬 저장

## 배포 방법

서버 기능이 없는 정적 사이트이므로 `index.html`과 문서를 정적 호스팅에 배포한다. 외부 API나 환경 변수는 필요하지 않다.

## 안전 원칙

광고, 외부 링크, 추적, 회원가입, 개인정보 수집, 채팅, 업로드, 결제를 사용하지 않는다. 자세한 기준은 `SAFETY_REQUIREMENTS.md`를 따른다.
