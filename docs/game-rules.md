# 게임 규칙

## 비밀숲 별 사냥

- 목표: 제한 시간 동안 순차적으로 나타나는 블록별을 빠르고 정확하게 눌러 최대한 많이 모은다.
- 레벨 1 새싹: 30초, 큰 별, 별 8개 달성 시 레벨 2 해제
- 레벨 2 탐험가: 35초, 더 빠른 중간 별, 별 12개 달성 시 레벨 3 해제
- 레벨 3 마스터: 40초, 아주 빠른 작은 별, 별 16개를 최고 목표로 제시
- 정답 클릭: 별·기본 점수·반응속도 추가 점수를 얻고 다음 별이 즉시 출현
- 별을 놓침: 벌점 없이 놓친 횟수만 기록하고 다음 별이 자동 출현
- 빈 영역 클릭: 잘못 클릭 수 증가, 점수 차감 없음
- 정확도: 성공 ÷ 전체 시도 × 100
- 평균 반응속도: 각 성공 목표가 나타난 뒤 눌릴 때까지 시간의 평균
- 종료: 레벨별 제한 시간 종료

## 보상

- 0~7개: 첫걸음 별 스티커
- 8~13개: 초록 탐험 배지
- 14~19개: 은빛 별 방패
- 20개 이상: 황금 별 왕관
- 보상은 획득한 별 수로만 정해지며 무작위·확률형 요소가 없다.

## 공통 원칙

- 점수는 학습 피드백이며 공개 순위에 사용하지 않는다.
- 시간 만료도 실패가 아니라 오늘 연습을 마친 것으로 표현한다.
- 소리는 사용자가 켠 경우에만 낮은 음량으로 재생한다.
