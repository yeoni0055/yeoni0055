# 게임 규칙

## 빛 블록 숲

- 목표: 제한 시간 동안 동시에 움직이는 빛 에너지 큐브를 빠르고 정확하게 눌러 숲의 등불을 복구한다.
- 레벨 1 새싹: 35초, 크고 느린 큐브 3개, 빛 블록 5개 달성 시 레벨 2 해제
- 레벨 2 탐험가: 35초, 더 빠른 중간 큐브 4개, 빛 블록 12개 달성 시 레벨 3 해제
- 레벨 3 마스터: 40초, 아주 빠른 작은 큐브 5개, 빛 블록 16개를 최고 목표로 제시
- 모든 큐브는 레벨별 이동 주기에 맞춰 화면 안의 다른 위치로 계속 움직인다.
- 정답 클릭: 빛 블록·기본 점수·반응속도 추가 점수를 얻고 클릭한 큐브는 즉시 다른 위치로 이동
- 황금 에너지 큐브: 항상 1개가 포함되며 클릭 시 빛 블록 3개와 해당 클릭 점수 3배를 확정 획득
- 빈 영역 클릭: 잘못 클릭 수 증가, 점수 차감 없음
- 정확도: 성공 클릭 수 ÷ 전체 클릭 시도 × 100. 황금 큐브의 빛 블록 3개는 성공 클릭 1회로 계산
- 평균 반응속도: 각 성공 목표가 나타난 뒤 눌릴 때까지 시간의 평균
- 종료: 레벨별 제한 시간 종료
- 다음 레벨 이동: 레벨 1은 빛 블록 5개, 레벨 2는 12개를 모으면 결과 화면에 다음 레벨 바로 도전 버튼을 표시한다. 이미 잠금 해제된 레벨도 같은 조건을 다시 달성하면 바로 이동할 수 있다.
- 목표 안내: 게임 중 다음 레벨까지 필요한 빛 블록의 남은 개수를 실시간으로 보여 준다.

## 정리 광산

- 광석, 도구, 수업 파일, 삭제 파일, 그림 파일, 발표 파일 6개를 알맞은 창고나 폴더로 옮긴다.
- 마우스 드래그와 `물건 선택 → 보관 장소 선택` 방식을 모두 지원한다.
- 정확한 분류는 광산 창고를 복구하고, 다른 장소는 점수를 깎지 않고 다시 안내한다.

## 한글 건축 성

- 1단계 한 글자 낱말부터 3단계 컴퓨터 낱말까지 16개를 차례로 입력한다.
- 정확히 입력할 때마다 성벽 블록이 한 칸 완성되고 연속 성공 점수를 얻는다.

## 영문 항해 섬

- 기본 자리 알파벳, 쉬운 영단어, 컴퓨터 단어까지 17개를 차례로 입력한다.
- 정확히 입력할 때마다 섬 사이 다리 블록이 한 칸 완성된다.

## 컴퓨터 수리 마을

- 마우스·키보드, 파일·폴더, 저장, 한쇼, 한셀에 관한 6개 문제를 푼다.
- 정답 블록을 고르면 건물 블록이 복구되며 다른 선택에도 감점이나 부정적 문구를 사용하지 않는다.

## 보상

- 0~7개: 첫걸음 별 스티커
- 8~13개: 초록 탐험 배지
- 14~19개: 은빛 별 방패
- 20개 이상: 황금 별 왕관
- 보상은 획득한 별 수로만 정해지며 무작위·확률형 요소가 없다.

## 공통 원칙

- 점수는 학습 피드백이며 공개 순위에 사용하지 않는다.
- 시간 만료도 실패가 아니라 오늘 연습을 마친 것으로 표현한다.
- 소리는 사용자가 켠 경우에만 낮은 음량으로 재생한다.
