# 콘텐츠 작성 지침

## 문장

- 한 문장에 한 가지 행동만 안내한다.
- 저학년이 이해할 수 있는 쉬운 낱말을 사용한다.
- `실패`, `탈락`, `틀렸어` 대신 `다시 찾아보자`, `실력이 자랐어요`를 사용한다.

## 타자 콘텐츠

- 한글: 학교, 컴퓨터, 마우스, 키보드, 친구, 바다, 하늘 등 짧고 중립적인 낱말
- 영문: A, B, CAT, DOG, SUN, GAME 등 기초 알파벳과 짧은 단어
- 폭력, 공포, 광고, 브랜드, 개인정보를 연상시키는 단어는 제외한다.

## 시각 콘텐츠

- 자체 CSS 도형, 일반 이모지, 프로젝트 내부 자산만 사용한다.
- 실제 게임 캐릭터·아이템·로고·공식 아이콘을 복제하지 않는다.
- 정답과 상태를 색상만으로 표현하지 않는다.
