# 아키텍처

## 구조

- `index.html`: 화면 마크업, 디자인 토큰과 반응형 CSS, 게임 상태 및 이벤트 로직
- 로컬 저장소: 비개인 설정과 최근 플레이 결과만 저장
- 문서: 제품, 안전, 디자인, 규칙 및 인수인계 정보

## 상태 모델

- 화면: `home`, `difficulty`, `game`, `result`
- 게임: 난이도, 점수, 성공 클릭, 잘못 클릭, 목표 수, 남은 시간, 일시정지, 반응시간
- 환경: 소리 설정, 애니메이션 감소 설정

## 확장 방향

기능이 커지면 CSS와 JavaScript를 분리하고 활동별 모듈을 만든다. 서버 기능은 개인정보와 운영 필요성이 검증되기 전까지 도입하지 않는다.
